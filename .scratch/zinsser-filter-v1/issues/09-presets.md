# 09 — Presets: Article default, Custom rule-family toggles, Editor team default

**What to build:** A Writer starts on the Article Preset by default, can switch Preset at any time regardless of team default, and — when using a Custom preset — toggles whole Rule families (never individual rules or POS categories). An Editor can set the team's default Preset but never lock a Writer's choice.

**Blocked by:** 01, 05, 06, 07

**Status:** ready-for-agent

- [ ] New Writer starts on the Article Preset with no configuration required
- [ ] Writer can switch their own Preset at any time, overriding any team default
- [ ] A novelist can disable the passive-voice family via a Preset so it stops firing
- [ ] Custom preset UI toggles Rule families (filler phrase, light-verb, nominalization, qualifier density, passive voice, redundant verb-pair) — never individual rule ids or POS categories
- [ ] Editor can set the team's default Preset
- [ ] Editor setting the team default never overrides a Writer's own already-chosen Preset
