# Deploy on Vercel's free Hobby plan: Next.js + Python Functions + Neon (free tier) + Auth.js

The requirements doc frames this as a web application without naming a stack. We chose Next.js on Vercel, with the Thai analysis pipeline (tokenizer, Lexitron lookup, rule engine) running as Vercel Python Functions rather than a separate hosted Python service — checked as of Feb 2026 the Python runtime's bundle limit is 500MB (5GB on Fluid Compute), comfortably enough for PyThaiNLP plus a preprocessed Lexitron index, so there's no need to split the analysis pipeline out to its own backend. Vercel dropped its own managed Postgres in Dec 2024 in favor of a Neon integration, so the database is Neon (free tier: 512MB storage) rather than a separate provider; auth is Auth.js's credentials provider for plain email+password, matching the earlier decision against SSO.

This runs entirely on free tiers (Vercel Hobby + Neon free), which only holds because usage is non-commercial: one Writer (the project's owner) and one Editor (a partner who reviews the drafts), never sold or run for a team. Vercel's Hobby plan terms prohibit commercial use — if that ever changes, this ADR's cost assumption needs revisiting and Vercel Pro (~$20/mo/seat) becomes necessary.
